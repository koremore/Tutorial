Musical Dice Game
=================

This folder contains the full Musical Dice game source code.

To run locally:
  1. Open a terminal in this folder
  2. npm install
  3. npm run dev
  4. Open http://localhost:5173

To build for production:
  npm run build
  npm start

Windows copy destination (requested):
  C:\_D_TRANSFER_i7\_Games\Musical Dices

To copy this archive on Windows (PowerShell):
  New-Item -ItemType Directory -Force -Path "C:\_D_TRANSFER_i7\_Games\Musical Dices"
  Copy-Item -Recurse -Force "<path-to-this-folder>\*" "C:\_D_TRANSFER_i7\_Games\Musical Dices\"

Or extract Musical-Dices-archive.zip into:
  C:\_D_TRANSFER_i7\_Games\
